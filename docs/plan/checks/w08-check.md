## Steps

1. **S0 Landfall & suggestion card.** Open `<client>/play.html?scenario=w08&skip=1`. Top centre below the resource bar, the **Stage Track HUD** shows 11 segments (`S0`–`S10`) with **S0** lit in orange (`S0 LANDING`, `Prepare ground, then build`, next condition `Command Hub T1 complete · 1 min`). Top right, the **HQ GOALS** panel (`0 / 2`) shows a suggestion card titled **Establish Colony** (`Prepare site, place Command Hub, and build 1 extractor + 1 generator`) with **ACCEPT** and **DO IT MYSELF**. Bottom left in the **BUILD [B]** tab, **Command Hub** is enabled while **Metals Extractor** and **Solar Collector Array** are greyed out and read `Unlocks at S1: Command Hub T1 complete · 1 min`.
2. **Accept "Establish Colony".** Click **ACCEPT** on the suggestion card (or pick `Establish Colony` in the `GOAL` dropdown and click **ADD GOAL**). The suggestion card closes, the header reads `HQ GOALS 1 / 2`, and an active goal card **Establish Colony** (`ACTIVE`, progress bar `0% (0/4)`) appears in the list. In the **QUEUE** lane on the left, `Command Hub T1`, `Metals Extractor T1`, and `Solar Collector Array T1` are queued (`hq` orders) and the HQ drone starts preparing the Command Hub footprint.
3. **Command Hub completes → S1 First Light.** Open the dev console (**`` ` ``**) and run `warp 20`. Within a few seconds the Command Hub finishes; run `warp 1` to return to normal speed. A **STAGE REACHED** toast opens below the stage track reading **S1 First Light** (`Resources flow, and everything costs energy, terraforming included`) with an **UNLOCKED** reveal panel listing `Units: Harvester`, `Buildings: Metals Extractor, Minerals Extractor, Water Extractor, Biomass Extractor, Solar Collector, Wind Turbine`, `Orders: Harvest`, and a **DISMISS** button. Segment **S1** is now lit in orange, the next condition reads `extractor + generator · 2 min`, and in the **BUILD [B]**, **PRODUCTION [U]**, and **TERRAFORM [T]** tabs **Metals Extractor**, **Solar Collector Array**, and **Harvester Drone** are un-greyed, while next-stage items (**Pylon**, **Storage Depot**, **Builder Drone**, **FILL**, **BRIDGE**) appear greyed out with `Unlocks at S2: extractor + generator complete · 2 min`.
4. **S2 dwell countdown & `stage skip-dwell`.** In the dev console run `warp 20` until the HQ finishes the Metals Extractor and Solar Collector (`Establish Colony` reaches `4/4` and clears from `HQ GOALS`), then run `warp 1`. Look at the right end of the Stage Track HUD's next-condition row: the **dwell countdown badge** is active and counts down from `2:00` (`1:59`, `1:58`, …) — the colony stays at `S1` until the 2-minute minimum dwell elapses (`UO-LC-02`). In the dev console run `stage skip-dwell`. The console prints `stage dwell skipped (applied at tick …)` and the stage track immediately advances to **S2** (`S2 THE GRID`, `Grid reach, parallel workers, storage, night`) with the **STAGE REACHED — S2 The Grid** toast listing `Builder`, `Pylon`, `Depot`, `Storage Depot`, `Capacitor`, `Fill`, `Bridge`, `Dismantle`. (**Pylon**, **Storage Depot**, and **Builder Drone** are now un-greyed in the menus.)
5. **Priority sliders & rule-engine autopilot (`suggestion` at S2 vs `auto` at S3).** At `S2`, open the dev console and run `autopilot next`. Because the power lane was introduced at S1/S2, the rule engine only *suggests* at S2 (`UO-LC-05`): the console prints `autopilot next: energy (… bp) -> suggestion: wind (construction)`. Now look at the **HQ PRIORITIES** panel (bottom right, `SUM 250`): drag the **EXPANSION** slider from `50` to `80` (the sum badge updates to `280`, and the slider state persists across a page reload). Run `autopilot next` in the dev console again → the top weighted need shifts to expansion and prints `autopilot next: expand (… bp) -> suggestion: outpostBeacon (construction)`. Next, run `stage set 3` followed by `autopilot next` → at `S3` the power lane is one stage past its introduction, so the console prints `autopilot next: energy (… bp) -> auto: wind (construction)` (queues an `auto` order instead of a suggestion).
6. **Safety override (`stage trigger fauna`) & HQ goal limit.** In the dev console run `stage set 2` to return to `S2 The Grid`, then run `help stage` (which lists `overrides: fauna, rival, resource, power, storage`). Run `stage trigger fauna`. Before any dwell timer expires, the S3 safety override fires: the stage track jumps to **S3** (`S3 FIRST CONTACT`, `Threat and defense, supply cap`) and the **STAGE REACHED — S3 First Contact** toast shows the badge **`Safety Override: fauna`**. To check the HQ T1 goal queue cap (`2`), run `goal clear`, `goal add grow_economy metals 100`, `goal add secure_power 100`, and `goal add defend_colony` in the dev console → the first two queue (`HQ GOALS 2 / 2`) and the third prints `error: queueGoal rejected: goal_limit`; clicking `×` on a goal in `HQ GOALS` frees the slot.
7. **`/me.html` Ascendant progress counter** — *not in this landing* (W12 consumer; deferred with `W08-07` / `W08-28`, see `FF-64`). Skip.
8. **Wave off (`&waves=..07`).** Open `<client>/play.html?scenario=w08&waves=..07&skip=1` (or run `TA_WAVES=..07 npm run dev:restart` and reload `<client>/play.html?scenario=w08&skip=1`). There is **no** Stage Track HUD, **no** HQ Goals panel, **no** HQ Priorities panel, and **no** stage-locked items in the menus; the colony still ticks and plays normally.
