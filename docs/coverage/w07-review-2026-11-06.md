## Fixed findings and architecture changes

- **GP-89: group routes after terrain changes.** Local seating routes are rebuilt from the current position and current blockers. A 20-member regression checks all reachable assigned slots after adding a rock mid-route.
- **GP-88: firing cadence.** Fractional deadlines retain configured sustained rates at 5 TPS: 2/s produces 20 shots and 4/s produces 40 shots over ten seconds. Zero disables fire; the existing maximum remains one shot per tick.
- **GP-87: inconsistent combat approach.** Shared `combatApproachBand` and `footprintAttackRange` now serve fauna chase, provocation, waves, replay directives, generic attack and playground combat. A real 3×3-hub regression samples ant and spitter positions for 100 ticks, including stable stopping at the reachable footprint edge.
- **Combat through fog.** Stance acquisition, pursuit and the final firing gate now require colony spotting. A long-range weapon needs a spotter outside its own sight radius.
- **Duplicated/stale balance numbers.** The shared weapon resolver now supplies weapon range/DPS to movement, combat and previews. Range rings use the simulation’s spotting rule. Map fallback visibility and 3D colony/projector vision receive live compiled balance data rather than silently reverting to defaults. The original task has inconsistent ring examples; indicators now match authoritative rules without changing sight balance (1×1 turret sight is 5 tiles).
- **Live hive health tuning.** Health edits preserve the damage fraction and reconcile ECS, hive records and damage-detection baselines, preventing false provocation and stale maximum HP.
- **FA-38: missing live fauna motion reconstruction.** Routine transforms were suppressed until the 25-tick correction while live replicas never ran the tested replay helper. ReplicaCore now uses a separate shared motion service, with filtered welcome route/command/timing seeds, shared movement rules, authoritative corrections and prediction continuity. Production-path tests cover both hosts, mid-walk joins, batched updates, terrain changes, live tuning and resynchronization. Already-past new directives request a fresh welcome rather than silently applying late. An 80-HQ queue stress test also exposed insects starting 0.4 tile too early; sparse authoritative route transitions now synchronize pending/start/replan/cancel/arrival timing without streaming ordinary transforms. Batched updates and new colony orders after welcome are covered. Private route/search state stays inside the worker and is removed from renderer-bound views.
- **Prediction correction.** A positive authoritative snapshot can revive a predicted-dead insect; an older snapshot cannot undo a later death event. `CombatHealthTracker` separates reconciliation from the combat event orchestrator. `FaunaClientSync` separates directive/correction bookkeeping; reset clears checkpoints and diagnostic histories are bounded. Recent death tombstones are bounded while living health records remain available.
- **Projectile queue drift after reload.** Enqueue and impact removal previously replaced the blob value without updating its change stamp. Existing clients retained old projectiles while a reloaded client received the current queue. Both transitions now use the canonical stamped setter, with production-diff and real-browser reload coverage. Lossless compact queue encoding reduces repeated wire keys without omitting updates.
- **Stale predicted combat cadence.** Public stance-change detection ignored acquired targets, firing deadlines and return-to-anchor state. Those fields now synchronize through production server and local transport paths; pending-command prediction clones the correct cadence. Sparse per-field stance patches retain null/undefined clears, row deletion, batched updates and legacy full-map input without retransmitting unchanged records. The full-suite parity gate exposed a missing baseline when record creation and firing occurred in one tick; initial records now establish a complete baseline before sparse updates, with dedicated new/legacy-record regressions. Private vision, evasion and damage bookkeeping also stamp changes for full host diffs while staying out of client wire payloads.
- **Distinct projectile impacts.** Optional shot `firedTick` travels through the event contract and presentation deduplication key, avoiding collisions when shots from one source arrive at the same tick/cell. Legacy payloads remain accepted.
- **Mixed-build compatibility.** Compact combat updates now have an explicit protocol boundary (`DIFF_FORMAT=2`, `SIM_VERSION=3`), so an older client cannot silently accept updates it cannot decode. A built-in, lossless version-2 snapshot migration preserves canonical saves, including browser-host eligibility. The current client shows an explicit reload prompt on version mismatch; scenario reloads rejoin the existing planet. Already-loaded older bundles do not acquire this new prompt until manually refreshed (FA-39).
- **Production-mode unit fixtures accessed the default dev database.** The last logging failure revealed that changing `NODE_ENV` to production enabled snapshot restoration and persistent ledger activity in HTTP-only tests. Shared fixture defaults now disable persistence and background workers. Regression checks require an in-memory ledger and no persisted-planet query; request-log assertions still require exactly one correlated HTTP error. No default database reset or cleanup was performed (XC-45).
- **Browser harness reliability.** Continuous trace screenshots stalled software WebGL despite a healthy 5 TPS simulation. Traces retain DOM/network/source data and explicit screenshots. W06 auth tests now start from a ready colony; W01 retains cinematic coverage. A DOM observer checks the exact transient saving status without missing an 11 ms transition, and persistent failure/Retry assertions remain unchanged. W06 and W07 share independent-browser setup and cleanup (XC-42).
- **RN-74: misleading playground metadata.** Hive/March scenes now display live scene statistics; Units selection exits March and restores standalone geometry metadata.
- **RN-77: missing swarm instancing.** Shared `InsectSwarmRenderer` serves gameplay and playground, with per-instance animation/selection and matching shadow transforms. The packed shader fits WebGL’s 16-slot minimum. Chrome rendered 200 insects in three species batches; comparison against individual meshes differed by only 0.00749/255 on average. Individual hidden interaction proxies remain for picking, sockets and corpse lifecycle, so memory is still per entity.
- **XC-41: weak live reconnect coverage.** The test now joins the exact planet in an independent Chrome process with a distinct dev identity, compares common simulation ticks, reloads the join URL and checks recovery. It requires an active cohort, damaged hive and pending acid projectile rather than accepting empty queues. Local hosting has a separate persisted-reload check because independent local hosts cannot share a planet.

Gameplay decisions remain in `shared/sim`; rendering consumes those decisions. New responsibilities are split into shared rule services, client reconciliation services and a shared swarm renderer. Structure checks enforce inward imports, ≤500 lines per file and ≤100 per function. The review removes demonstrated duplication; passing these checks is not a formal proof that every abstraction in the branch is ideal.
